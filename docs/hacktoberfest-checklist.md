# Hacktoberfest 2026 checklist

For the DEV **Hacktoberfest Open-Source AI Challenge: Week 1 — Touch Grass** (`#hf26challenge`). Submissions are due **Sunday, October 11, 2026 at 11:59 PM PDT** (Monday, October 12, 03:59 in Brasília). The rules are on the [challenge page](https://dev.to/challenges/hacktoberfest-week1-2026-10-05).

## Repository

- [x] Public repository with an open-source license (MIT)
- [x] Started inside the challenge window (October 5, 2026)
- [x] README explains what it is, how to run it and why open matters
- [x] CONTRIBUTING, Code of Conduct, Security policy, issue and PR templates
- [x] CI: gofmt, go vet, go test -race (with PostgreSQL), frontend build
- [x] No secrets, real photos or coordinates committed

## DEV post

- [ ] Published on DEV using the **submission template on the challenge page**
- [ ] Tag `#hf26challenge` (plus up to three more, e.g. `#opensource #ai #go`)
- [ ] What it is and who it's for: neighbors who walk their streets and want problems reported clearly
- [ ] **Why open matters**: photos and locations never leave the notebook; works without signal; no per-photo cost; swap models with one variable; open data (OpenStreetMap, BrasilAPI, IBGE)
- [ ] Where open beat closed: e.g. analyzing every photo of a walk costs nothing, and the 9-of-9 field result came from a model you can run and inspect yourself
- [ ] Demo: screenshots or a short screen recording from the phone, and a link to this repository
- [ ] **Bonus — taken outside:** the Joaçaba walk (7 min, 9 points, 9/9 categories kept), what worked and what did not (GPS pauses with the screen off; ~80 s per photo on a small GPU)
- [ ] Prize category: **Best Use of Gemma**. Explain the vision input, structured output and the needs-info question
- [ ] Optional: save this agent session with DevRelay and embed or link it
- [ ] AI disclosure as DEV's guidelines require (the post and the code were AI-assisted)
